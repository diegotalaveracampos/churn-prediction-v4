# 🎯 Predicción de Abandono de Clientes (Churn Prediction)

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Machine Learning](https://img.shields.io/badge/Machine-Learning-orange)
![Streamlit](https://img.shields.io/badge/Web-App-red)

Proyecto completo de Data Science para predecir qué clientes tienen mayor probabilidad de abandonar un servicio de telecomunicaciones.

## 📊 Descripción del Proyecto

Este proyecto implementa un sistema completo de Machine Learning para:
- **🔍 Analizar** patrones históricos de abandono de clientes
- **🤖 Predecir** clientes en riesgo de abandonar el servicio  
- **💡 Proporcionar** insights accionables para estrategias de retención
- **📈 Visualizar** resultados mediante un dashboard interactivo

## 🚀 Características Principales

- **📊 Análisis Exploratorio** completo (EDA) con visualizaciones interactivas
- **🤖 Múltiples modelos** de Machine Learning comparados (Logistic Regression, Random Forest, XGBoost)
- **🎯 Dashboard interactivo** con Streamlit para predicciones en tiempo real
- **🔍 Explicabilidad del modelo** con análisis SHAP
- **📈 Análisis de impacto** en el negocio y ROI estimado
- **💾 Pipeline completo** de preprocesamiento y modelado

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python 3.8+
- **ML & Estadística:** Scikit-learn, XGBoost, NumPy, Pandas
- **Visualización:** Matplotlib, Seaborn, Plotly
- **Dashboard:** Streamlit
- **Explicabilidad:** SHAP
- **Notebooks:** Jupyter
- **Control de Versiones:** Git
